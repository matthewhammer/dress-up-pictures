Messed Up Dress Up: every picture, run by run

Every picture in Messed Up Dress Up, at each run of the archive: every background (with and without the friend; since 2026-10-17 each also with 🔬 🧩 what it is made of and with 🔬 🧱 the collision boxes), every chip menu at its defaults, and the friend climbing each place’s ladder. Each drawing is an SVG, its settings (Load opens them in the game) and a thumbnail; the PNG is drawn from the SVG when you ask for it. Every run writes the same paths, so only the newest is on this site: each earlier one is a git tag, which the picture viewer reads. The runs up to 2026-10-17, with their PNGs, are also kept as they were, in dress-up-pictures-2026-10-18. 🎵 The music.
